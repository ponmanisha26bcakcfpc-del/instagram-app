📸 Instagram App UI Design – Low-Fidelity

✨ Project Overview

This is an Instagram App Low-Fidelity UI Design created using Figma. The application provides a simple wireframe interface for users to share photos, view posts, watch stories and reels, follow friends, and interact through likes, comments, and messages.

🎯 Objective

The main objective of this project is to design a simple and user-friendly Instagram interface using basic shapes, buttons, and layouts to show the app's structure and navigation.
